# Asset sources

- `hero.svg`: original vector composition for this profile. Designed for GitHub dark backgrounds; no external fonts, scripts or animation.
- `wildberries-mark.svg`: marketplace icon downloaded from the [official RWB website](https://rwb.ru/), [source SVG](https://rwb.ru/assets/svg/wb-logo.svg), on 2026-10-30. Original path and viewBox retained; black fill changed to pink for visibility on GitHub dark backgrounds. This is the Wildberries marketplace mark, not the RWB corporate wordmark.
- `innopolis-mark.svg`: IU monogram from the [university services website](https://iuservices.innopolis.university/), [source SVG](https://static.tildacdn.com/tild3632-6632-4633-a638-373239316166/Logo.svg), downloaded on 2026-10-30. The first three source paths form the complete monogram. Original geometry and #40BA21 colour retained; the department wordmark is omitted. The 48 × 48 viewBox contains the entire mark, including both full-height stems of U.

Logos remain the property of their respective owners. Both marks are displayed at 24 × 24 px alongside native README text, with no card background or border.
